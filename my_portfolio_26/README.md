# Abhishek Portfolio (React + TypeScript + Vite + Tailwind + Framer Motion)

    npm install
    npm run dev      # http://localhost:5173
    npm run build    # production build in /dist

All content is in `src/data.ts`. Look for `TODO verify` comments.
Add your resume at `public/resume.pdf`. Add project/profile images under `public/` and set the `image` field.
Palette tokens are in `tailwind.config.js`: white #FFFFFF, purple #A74CA9, plum #24162B, soft #F5F1F7, muted #6F6472.
